# Valkyrie no Bouken : Toki no Kagi Densetsu ( Thai Translation)
Patch แปลภาษาไทยของเกม Valkyrie no Bouken Toki no Kagi Densetsu ฉบับรีเมคบนเครื่อง PlayStaion  
ซึ่งเป็น 1 เกมจากทั้งหมด 4 เกมรีเมคในชุดรวมของเกม Namco Anthology 2 

อ้างอิงงานผลงานแปลภาษาอังกฤษของ eadmaster  
แต่ไม่แก้ไขชุดฟอนต์ใน bios scph5500.bin เพราะจะกระทบเกมอื่นๆ ใช้การเพิ่มชุดฟอนต์ภาษาไทยใหม่เข้าไปในตัวเกม  

*หมายเหตุ: ผลงานมีการใช้ Claude ในการช่วยพัฒนา

## Why I made this
ความชื่นชอบส่วนตัวต่อเกม เกมซีรีส์ Valkyrie นี้เป็นหนึ่งในซีรีส์เกม Classic ของค่า Namco ที่ผมชื่นชอบมาก  
ฉบับรีเมคบน PS1 นี้เป็นเวอร์ชั่นที่เปลี่ยนเกมเพลย์ต้นฉบับให้มีความคล้ายคลึงกับภาคที่ 2 Valkyrie no Densetsu ซึ่งก็ถูกใจผมมากเช่นกัน
